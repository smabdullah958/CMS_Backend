# Complain Management System Backend

This is the backend of a Complaint Management System built during my personal practice to improve my development skills. It allows students to submit complaints, which are then stored in a database. The system includes role-based authentication , generates a unique complaint ID for every submission, and sends an automated email notification to the principal .

I created this project to better understand backend concepts such as:

RESTful API design
User authentication & role-based access
Database modeling
Email integration
It has greatly helped me grow technically and provided hands-on experience with building real-world applications.
